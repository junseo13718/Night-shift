야간근무 — 편의점 알바 시뮬레이터

실행 (Windows)
1. ZIP 파일의 압축을 전부 해제합니다.
2. START.cmd를 더블클릭합니다. 브라우저가 자동으로 열립니다.
3. 웹캠으로 출근하기를 누르고 카메라 권한을 허용합니다.
   카메라 없이 하려면 마우스로 먼저 체험하기를 누릅니다.
4. 종료할 때 서버 창에서 Ctrl+C를 누르거나 창을 닫습니다.

이 컴퓨터의 Codex에 포함된 Node.js를 우선 사용합니다.
다른 컴퓨터에서는 Node.js가 설치되어 있어야 합니다.
라이브러리와 모델 다운로드를 위해 인터넷 연결이 필요합니다.
index.html을 직접 여는 대신 실행기를 사용하세요.
PC의 Chrome 또는 Edge 브라우저를 권장합니다.

조작
- 캐릭터는 계산대에 고정되어 있습니다. 걷기 조작은 없습니다.
- 웹캠 모드: 시작할 때 화면 정면을 보고 약 1.5초간 움직이지 않으면 정면 기준을 맞춥니다.
- 고개를 왼쪽/오른쪽/위/아래로 돌리면 같은 방향으로 게임 시야가 계속 회전합니다.
- 편하게 정면을 보면 시야 회전이 멈춥니다. 이렇게 전체 360도를 둘러볼 수 있습니다.
- R 또는 정면 재설정 버튼: 현재 시야를 유지하고 편한 자세를 새 정면 기준으로 맞춥니다.
- 얼굴이 보이지 않으면 시야가 멈춥니다. 기준을 맞추는 동안 게임 시간도 멈춥니다.
- 웹캠 모드의 시야는 고개로만 조종합니다. 손으로 집기/펀치는 그대로 사용합니다.
- 마우스 체험 모드: 마우스로 상하좌우 시야를 돌립니다. 잠금 미지원 시 드래그합니다.
- 화면 중앙의 점으로 상품을 조준합니다.
- 웹캠: 엄지와 검지를 붙이면 집기, 펴면 내려놓기.
- 상품을 집고 바코드 리더기를 조준한 뒤 손가락을 펴면 스캔합니다.
- 모든 상품을 스캔한 뒤 카드 리더기를 조준하고 집기 동작으로 결제합니다.
- 택배 손님은 왼쪽 유스 로커를 조준하고 집기 동작으로 응대합니다.
- 주먹을 쥐면 게임 속 주먹이 날아갑니다. 손님을 때리면 평점이 떨어집니다.
- 마우스 모드: 클릭으로 집기/놓기/결제, F로 펀치.
- ESC: 일시정지. 화면의 조작법 ? 버튼으로 안내를 볼 수 있습니다.

게임 규칙
- 실제 근무 시간은 4분이며 일시정지 중에는 시간이 흐르지 않습니다.
- 손님마다 구매 상품 또는 택배 요청이 있습니다.
- 손님이 오래 기다리면 떠나며 평점이 떨어집니다.
- 종료 화면에서 응대 인원, 매출, 평점과 놓친 손님을 확인합니다.

카메라
영상은 브라우저에서 MediaPipe로 처리하며 서버로 전송하지 않습니다.
손바닥 전체가 보이도록 하고 밝은 곳에서 사용하세요.
주먹과 집기 사이에 손을 펴서 다음 동작을 인식시켜 주세요.
카메라 권한, 조명, 손의 각도에 따라 인식 품질이 달라질 수 있습니다.
게임 종료 시 카메라를 해제합니다.

구성
game/index.html — 한국어 화면
game/style.css — 화면 스타일
game/head-look.js — 얼굴 방향 계산, 정면 보정, 부드러운 시야 회전
game/game.js — 3D 공간, 손 인식, 손님, 거래, 타이머
server.cjs — 로컬 전용 HTTP 서버
START.cmd — Windows 실행기

검증: JS 문법, 3D 화면 및 손님 표시, 조작 안내 및 일시정지 UI,
상품 집기/스캔/잘못 놓기/결제 조건/매출/택배/대기 초과 로직.
추가 검증: 고개 상하좌우 방향, 정면 보정, 흔들림 억제, 얼굴 추적 손실 시 정지.
실제 웹캠의 고개/손동작 인식과 4분 전체 플레이는 미검증입니다.
온라인 배포는 현재 환경의 소스 전송 승인 제한으로 완료되지 않았습니다.
