휴대폰으로 플레이하기

지금 바로 하는 방법 — 같은 Wi-Fi에서 터치로 플레이
1. PC에서 압축을 풀고 START-PHONE.cmd를 실행합니다.
2. 휴대폰을 PC와 같은 Wi-Fi에 연결합니다.
3. PC의 실행 창에 표시되는 http://192.168...:4174 같은 주소를
   휴대폰의 Safari 또는 Chrome 주소창에 입력합니다.
4. 카메라 없이 터치로 시작하기를 누릅니다.
5. 화면을 밀어 시야를 돌리고, 아래 버튼으로 집기/놓기/결제/펀치를 합니다.
6. 오른쪽 위 Ⅱ 버튼으로 일시정지합니다. 가로 화면을 권장합니다.
7. 게임 중 PC의 실행 창은 열어 두세요. 종료 시 창을 닫습니다.

연결이 안 된다면
- PC와 휴대폰이 같은 Wi-Fi인지 확인하세요. 게스트 Wi-Fi에서는 기기 사이 연결이 막힐 수 있습니다.
- Windows에서 네트워크 허용을 물으면 본인이 신뢰하는 개인 네트워크에서만 허용하세요.
- 4174 포트가 이미 사용 중이라면 기존 게임 서버를 닫고 다시 시작하세요.
- 휴대폰에서 127.0.0.1 주소를 쓰면 PC에 연결되지 않습니다. 실행 창의 Wi-Fi 주소를 사용하세요.

휴대폰 전면 카메라로 고개·손 인식하기
- 브라우저 보안 규칙 때문에 휴대폰의 카메라는 HTTPS 주소에서만 사용할 수 있습니다.
- 위의 Wi-Fi HTTP 주소에서는 터치 조작을 사용하세요.
- game 폴더의 파일을 HTTPS 정적 호스팅에 게시하면 휴대폰에서도
  웹캠으로 출근하기로 전면 카메라를 사용할 수 있습니다.
- 고개와 손을 함께 인식하려면 휴대폰을 받침대에 고정하고 얼굴과 손이
  모두 카메라에 보이게 해 주세요. 정면 재설정 버튼으로 기준을 다시 맞춥니다.
- 현재 온라인 HTTPS 게시 주소는 없습니다. 이전 배포 과정에서 소스 전송 승인이 차단됐습니다.

변경 내용
- 세로/가로 화면과 화면 가장자리 안전 영역에 맞춘 UI
- 카메라 없이 화면 밀기 + 집기/놓기/결제/펀치 버튼
- 전면 카메라 요청, 고개·손 인식, 화면의 정면 재설정 버튼
- 휴대폰 GPU를 위한 정적 사물 묶음 렌더링과 그림자/해상도 조정
- 브라우저에서 다른 앱으로 전환하면 일시정지

실제 Android/iPhone 기기에서 카메라와 성능은 아직 검증하지 못했습니다.
